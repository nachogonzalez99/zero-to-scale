# 0003. Documentation as code

- **Status:** Accepted
- **Date:** 2026-10-28

## Context

Docs kept apart from code go stale.

## Decision

All company documentation lives in the repo as Markdown.

## Alternatives considered

- Wiki or Notion: easier editing, but not versioned with the code.

## Consequences

- Docs are reviewed and versioned like code.
- Editing requires Git.
